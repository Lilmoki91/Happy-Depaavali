# Happy Deepavali

A festive single-page web experience inspired by the celebration of Diwali. This project is a playful interactive website featuring glowing diyas, decorative home scenes, a rangoli art studio, wish lanterns, and personal notes — all designed in a warm, colorful holiday style.

## ✨ Highlights

- Interactive Diwali-themed landing page
- Multiple festival sections: Discover, Lights, Rangoli, Home, Sharing, Sky, and Notes
- Customizable visual themes (Classic, Rose, Lavender, Night)
- Rangoli canvas with drawing tools, symmetry modes, stencils, and save functionality
- Decor placement system for a virtual festive home scene
- Fireworks and floating lantern wish experience
- Notes storage using browser storage (IndexedDB/local fallback)
- Fully static HTML/CSS/JavaScript project with no build step

## 🧩 Project overview

This website is built as a single-page app using plain HTML, CSS, and JavaScript. It creates a cozy Diwali-inspired experience with rich styling, animations, and small interactive tools that make the page feel like a digital festival card.

## 🌐 Main pages

- Home: Welcome screen and festival overview
- Discover Diwali: Cultural background and traditions
- Lights & diyas: Showcase of glowing lamps and festive imagery
- Rangoli art: Drawing canvas with color, brush size, stencils, and saved designs
- My Diwali home: Add flowers, diyas, lanterns, and rangoli to a custom room scene
- Sharing sweetness: Inspiration gallery for decorated homes and festive details
- Sky & wishes: Fireworks and floating lantern wishes
- My notes: Save personal notes and memories in-browser

## 🛠️ Tech stack

- HTML5
- CSS3
- JavaScript
- IndexedDB for local persistence
- No framework or package installation required

## ▶️ How to run

Because this is a static website, you can run it in one of the following ways:

1. Open `index.html` directly in your browser.
2. Or serve it locally:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
